AKRITI & RANJEET - RENDER WEBSITE DEPLOYMENT

Files:
- index.html : Complete single-file wedding website
- render.yaml : Optional Render Blueprint settings

PUBLISH USING GITHUB AND RENDER
1. Extract the ZIP.
2. At github.com/new create a repository, for example akriti-ranjeet-wedding.
3. Upload index.html and render.yaml directly to the repository root and commit.
4. In dashboard.render.com choose New > Static Site.
5. Connect your GitHub repository and select the main branch.
6. Settings for this plain HTML website:
   Name: akriti-ranjeet-wedding (if available)
   Build Command: echo "No build required"
   Publish Directory: .
7. Create/Deploy Static Site and copy your public onrender.com address.

IMPORTANT: The QR code for your current Netlify link will continue to point to Netlify. If you want the QR to open your Render website, generate a new QR code after Render publishes.

Before sharing publicly, confirm all wedding event dates, residence address, venue directions, contact details, and video content are correct.
